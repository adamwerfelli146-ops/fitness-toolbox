# 🏋️‍♂️ Fitness Toolbox – Your All-in-One Training Companion

**A comprehensive, offline-friendly web app for fitness enthusiasts around the world.**

— Plan your nutrition, target specific muscles, and build your ideal weekly workout schedule all in one place.

 **🔗 Live Demo: https://adamwerfelli146-ops.github.io/fitness-toolbox/**

---

## ✨ Features
- **1. Calories & Macros Calculator**
Calculate your maintenance, bulking (+300 kcal), or cutting (–300 kcal) calorie targets
Get personalized macronutrient breakdowns (protein, carbs, fat) based on body weight
Uses the Mifflin-St Jeor equation (BMR) + activity multiplier for accuracy
Works accurately for all genders (automatically adapts calculation)
- **Pomodoro Timer**: 25-minute work sessions + 5-minute breaks with visual mode indicator.
- **Smart UI Feedback**:  
  - 🟢 Green timer = Work Time  
  - 🟠 Orange timer = Break Time  
- **Keyboard Support**: Press `Enter` to add a task quickly.
- **Fully Offline**: No internet? No problem. Works 100% in your browser.

## 🛠️ Tech Stack
- **Frontend**: HTML5, CSS3, Vanilla JavaScript (ES6+)
- **Data Storage**: `localStorage` (no backend required)
- **Design**: Modern dark theme with glassmorphism effects, responsive layout

## 💻 Local Use
1. Save `index.html`, `style.css`, and `script.js` in the same folder  
2. Open `index.html` in any modern browser (Chrome, Firefox, Edge, Safari)  
3. Start focusing—no installation, no server, no dependencies!

> ✅ Works on mobile and desktop  
> 🔒 Your data never leaves your device

## 🎨 UI Highlights
- Smooth animations and hover effects
- Clean typography with monospace timer display
- Gradient accents in cyan/teal theme
- Responsive layout for all screen sizes
